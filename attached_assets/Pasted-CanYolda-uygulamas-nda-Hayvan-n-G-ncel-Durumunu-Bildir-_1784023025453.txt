4. RESPONSE PARSING MANTIĞINI DÜZELT
==================================================

Frontend'de hiçbir API response'unu kör şekilde response.json() ile parse etme.

Güvenli response parser kullan.

Mantık:

const contentType = response.headers.get("content-type") || "";
const rawText = await response.text();

if (!response.ok) {
  console.error("API ERROR", {
    status: response.status,
    contentType,
    rawText,
  });

  throw new Error(
    `API request failed with status ${response.status}`
  );
}

if (!contentType.includes("application/json")) {
  console.error("INVALID API RESPONSE", {
    contentType,
    rawText,
  });

  throw new Error("Server returned a non-JSON response");
}

let data;

try {
  data = JSON.parse(rawText);
} catch (error) {
  console.error("JSON PARSE ERROR", {
    rawText,
    error,
  });

  throw new Error("Invalid JSON response received from server");
}

Ancak sadece parser eklemek yeterli değildir.

HTML response üreten backend/API problemi mutlaka düzeltilmeli.

7. DOUBLE SUBMIT KONTROLÜ
==================================================

"Güncellemeyi Kaydet" butonunun tek tıklamada yalnızca 1 request gönderdiğini doğrula.

Kontrol et:

- duplicate onPress
- useEffect side effect
- mutation double execution
- form submit + button onPress conflict
- React StrictMode side effects

Saving state ekle:

if (isSaving) return;

Request başlarken:

setIsSaving(true);

finally:

setIsSaving(false);

İşlem sırasında butonu disabled yap.

Tek kullanıcı aksiyonu = tek database write olmalı.
