# Replit Agent Brief — "Evcilim" Pet Care Module

Build a mobile-first web app (PWA) for pet care tracking. The UI language is TURKISH — use the exact Turkish strings provided below. Follow the design system strictly.

## Tech requirements
- Mobile-first responsive web app (max content width ~430px, centered on desktop)
- React + Tailwind CSS (or similar modern stack you prefer)
- Persistent database (Postgres or built-in Replit DB) — no mock-only data
- PWA-ready: installable, works as standalone app on a phone
- All dates displayed in Turkish format: "18 Temmuz 2024, Perşembe"

## Design system
- Primary color: purple/violet (#7C3AED family), used for active states, icons, buttons, active tab underline
- Backgrounds: very light lavender (#F7F5FF) page background, white cards
- Cards: large border radius (16–24px), soft subtle shadows, generous padding
- Status colors:
  - Orange (#F97316 family) = upcoming / due soon ("Yaklaşıyor")
  - Green (#16A34A family) = up to date / ok ("Güncel")
  - Red (#EF4444 family) = overdue ("Gecikmiş") and destructive buttons
- Pills/badges: rounded-full, tinted background with darker text of same hue
- Icons: outline style (Lucide or Tabler)
- Typography: clean sans-serif; bold section titles; secondary text in gray

## Navigation
Bottom tab bar with 5 tabs (icons + labels):
Harita · Akış · Hayvanlar · Evcilim (active, heart icon) · Hesap
Only "Evcilim" needs to be functional; other tabs can be placeholder pages.

Top of Evcilim page: two-tab switcher "Evcilim" | "Sahiplendirme" (Sahiplendirme is a placeholder), plus a notification bell icon with unread dot.

## Data model (minimum)

- **pets**: id, name, species, breed, sex, birth_date, adoption_date, color, neutered (bool), weight_kg, height_cm, temperament, allergies, special_note, photo_url
- **vaccines**: id, pet_id, name, date_given, next_due, notes, status (computed)
- **appointments**: id, pet_id, title, date, time, clinic_name, clinic_location, vet_name, reminder_at, reminder_enabled (bool), notes, recurrence (none|1m|3m|6m|12m), status (upcoming|done|cancelled)
- **reminders**: id, pet_id, title, due_date, type (vaccine|appointment|food|custom), color
- **feeding**: id, pet_id, food_stock_kg, daily_amount_g (days-left computed)

Seed the database with the sample pet "Luna" and all the sample data above so the app looks exactly like the design on first run.

## Behaviors
- Multiple pets supported; dashboard carousel switches the active pet and all sections update accordingly
- All lists support add / edit / delete
- Reminders sorted by date ascending; overdue items highlighted red
- Empty states with friendly Turkish messages (e.g. "Henüz aşı kaydı yok")
- No login required for v1 (single-user); structure code so auth can be added later
