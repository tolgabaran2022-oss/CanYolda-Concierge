BUILD A COMPLETE PET ADOPTION REQUEST AND NOTIFICATION SYSTEM

Implement a complete production-ready "Sahiplendirme Talebi" system for the existing Sahiplendirme section.

IMPORTANT:
Do not redesign the existing Sahiplendirme page.
Preserve the current premium purple UI.
Use the existing authentication, user profile, listing, notification and messaging infrastructure where possible.

The notification bell in the top-right of the Sahiplendirme screen must now have a real purpose.

==================================================
CORE FEATURE
==================================================

Create this complete adoption flow:

User opens an adoption listing
→ taps "İletişim" or "Sahiplenmek İstiyorum"
→ adoption request form opens
→ user completes a short application
→ request is sent to the listing owner
→ listing owner receives a Sahiplendirme notification
→ owner reviews the request
→ owner can accept, reject or start messaging
→ both users can communicate
→ adoption process status is tracked

This must use real authenticated users and real database records.

Do not use fake notifications.
Do not use random users.
Do not hardcode adoption requests.
