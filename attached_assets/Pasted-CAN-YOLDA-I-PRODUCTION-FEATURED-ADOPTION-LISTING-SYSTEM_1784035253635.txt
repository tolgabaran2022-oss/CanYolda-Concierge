DO NOT TRUST is_featured ALONE
==================================================

This is critical.

The UI must not display the featured badge only because:

Always validate the expiration state.

Conceptually:

const isActivelyFeatured =
  promotion.status === 'active' &&
  new Date(promotion.expires_at).getTime() > Date.now();

If denormalized listing fields are used:

  listing.is_featured === true &&

Do not allow an expired promotion to remain visually featured because of stale boolean state.

EXPIRATION ARCHITECTURE
==================================================

Do not rely only on:

setTimeout()

in the mobile application.

Do not rely on the user keeping the app open.

Do not rely on a client-side timer.

Promotion expiration must be determined by server/database time.

Use:

expires_at > NOW()

for active featured queries.

Optionally, according to the existing backend architecture, use a scheduled backend job to update:

status = expired

and:

is_featured = false

But even if the scheduled job is delayed, the public listing query must treat:

expires_at <= NOW()

as NOT FEATURED.

This guarantees correct ranking.
