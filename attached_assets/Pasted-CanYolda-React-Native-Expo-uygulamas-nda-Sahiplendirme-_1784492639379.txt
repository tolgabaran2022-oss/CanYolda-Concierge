CanYoldaşı React Native (Expo) uygulamasında, “Sahiplendirme” ana sayfasında bulunan “İlan verirken dikkat et” kartını kaldır ve yerine aynı alanı kaplayan, premium ve animasyonlu bir “Çok Yakında” banner bileşeni oluştur.

ÖNEMLİ:
- Mevcut sayfanın geri kalan tasarımını, navigasyonunu, işlevlerini veya veri akışını değiştirme.
- Sadece “İlan verirken dikkat et” kartını bu yeni banner ile değiştir.
- Banner hem iOS hem Android’de sorunsuz çalışmalı.
- Expo Web görünümü de responsive olmalı.
- Uygulamanın mevcut mor/lila CanYoldaşı tasarım dili korunmalı.
- Banner ekran dışına taşmamalı ve altındaki istatistik kartlarını aşağı doğru gereksiz şekilde itmemeli.

Eğer Reanimated projede yoksa yalnızca bu özellik için ağır bağımlılık ekleme. React Native Animated API kullan.

A. Hayvan ve klinik görseli floating animasyonu

Görsel çok yavaş şekilde yukarı-aşağı hareket etsin:

Başlangıç:
translateY: 0

Hedef:
translateY: -3

Son:
translateY: 0

Süre:
3000 ms

Easing:
Easing.inOut(Easing.ease)

Loop:
sonsuz

Animasyon çok hafif olmalı. Görsel zıplamamalı.

Örnek mantık:

Animated.loop(
  Animated.sequence([
    Animated.timing(floatValue, {
      toValue: -3,
      duration: 1500,
      easing: Easing.inOut(Easing.ease),
      useNativeDriver: true,
    }),
    Animated.timing(floatValue, {
      toValue: 0,
      duration: 1500,
      easing: Easing.inOut(Easing.ease),
      useNativeDriver: true,
    }),
  ])
).start();
