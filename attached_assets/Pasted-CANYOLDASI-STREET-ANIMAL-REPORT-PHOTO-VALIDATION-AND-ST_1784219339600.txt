3. ANIMAL-ONLY IMAGE VALIDATION
==================================================

The photo must contain a real animal.

Reject photos containing only:

- people
- selfies
- furniture
- food
- vehicles
- buildings
- documents
- screenshots
- phone/computer screens
- advertisements
- memes
- landscapes without an animal
- random objects

Allow real animals such as:

- cats
- dogs
- birds
- rabbits
- turtles
- horses
- cows
- goats
- sheep
- wildlife
- injured or abandoned animals

Use a provider-independent validation layer:

AnimalImageValidationService

The mobile UI must not call an AI provider directly.

The backend or secure service must be the authority.

Expected result model:

type AnimalImageValidationResult = {
  isAnimalDetected: boolean;
  confidence: number;
  detectedAnimalTypes: string[];
  isLikelyScreenshot?: boolean;
  isLikelyScreenPhoto?: boolean;
  qualityPassed: boolean;
  rejectionReason?: string;
};

Do not hardcode fake success such as:

return { isAnimalDetected: true };

==================================================

Suggested behavior:

The exact thresholds must be environment/config controlled, not scattered across UI components.
