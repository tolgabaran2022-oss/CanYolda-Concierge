9. LOAD THE COUNT ON SCREEN OPEN

When the report detail screen opens, fetch the existing location open count.

Example:

const fetchLocationOpenCount = async () => {
  const { count, error } = await supabase
    .from('report_location_opens')
    .select('*', { count: 'exact', head: true })
    .eq('report_id', report.id);

  if (error) throw error;

  setLocationOpenCount(count ?? 0);
};
