Fix the missing data connection between completed animal-help updates and the “Ayın Kahramanları” monthly leaderboard.

CURRENT BUG

The real user flow is:

1. A user opens a reported street-animal condition.
2. The user taps “Yardım Et.”
3. The “Hayvanın Güncel Durumunu Bildir” form opens.
4. The user adds a current photo.
5. The user selects the help action performed.
6. The user submits the update successfully.
7. The help update may appear to be saved.
8. However, the user’s help count and points do not appear or update in “Ayın Kahramanları.”

The leaderboard is not receiving, aggregating, or refreshing the completed help data.

Do not fix this using mock users, hardcoded scores, or local frontend state.
