4. NORMALIZE LEGACY STATUS VALUES
==================================================

Inspect existing database records.

Normalize these values before filtering.

Example logic:

const normalizeAnimalStatus = (value?: string) => {
  const normalized = value
    ?.trim()
    .toLocaleLowerCase('tr-TR')
    .replace(/ı/g, 'i')
    .replace(/ğ/g, 'g')
    .replace(/ü/g, 'u')
    .replace(/ş/g, 's')
    .replace(/ö/g, 'o')
    .replace(/ç/g, 'c');

  switch (normalized) {
    case 'ac':
    case 'hungry':
      return 'hungry';

    case 'yarali':
    case 'injured':
      return 'injured';

    case 'saglikli':
    case 'healthy':
      return 'healthy';

    case 'bilinmiyor':
    case 'belirsiz':
    case 'unknown':
      return 'unknown';

    default:
      return 'unknown';
  }
};

'aç'

Use normalized canonical status values.
