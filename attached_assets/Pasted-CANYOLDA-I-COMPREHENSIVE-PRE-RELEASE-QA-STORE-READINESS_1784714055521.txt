AMAÇ

CanYoldaşı uygulamasını ilk App Store ve Google Play yayını öncesinde gerçek kullanıcı davranışlarıyla kapsamlı şekilde test et.

Bu görev yalnızca kod incelemesi değildir.

Kod incelemesi yapılabilir ancak runtime davranışı görülmeden PASS verilmez.

Yeni özellik ekleme.
Tasarımı değiştirme.
Ürün fikri önerme.
Sadece hata bul, doğrula ve yayın engellerini raporla.

==================================================
EN ÖNEMLİ TEST KURALI
==================================================

Bir özelliğe yalnızca kodunu inceleyerek PASS verme.

PASS verilebilmesi için:

1. Özellik gerçekten çalıştırılmalı.
2. İlgili kullanıcı aksiyonu uygulanmalı.
3. Beklenen UI sonucu görülmeli.
4. Backend işlemi varsa API ve database sonucu doğrulanmalı.
5. Console ve network üzerinde beklenmeyen hata olmamalı.
6. Uygulama yeniden açıldıktan sonra kalıcı veri tekrar okunmalı.
7. Platforma özel test gerçekten o platformda yapılmalı.

Sonuç sınıflandırması:

PASS:
Gerçekten çalıştırıldı ve doğrulandı.

FAIL:
Çalıştırıldı ve hata görüldü.

STATIC REVIEW:
Yalnızca kod veya configuration incelendi.

BLOCKED:
Test ortamı, cihaz, hesap, secret veya build olmadığı için çalıştırılamadı.

NOT TESTED:
Henüz test edilmedi.

Web sonucunu Android PASS kabul etme.
Android sonucunu iOS PASS kabul etme.
Expo Web önizlemesini native mobil test olarak kabul etme.
