CAN YOLDAŞI — MAP MARKER TO ANIMAL REPORT CARD SYNCHRONIZATION

Implement a production-ready synchronization flow between map markers, the "Yakındaki Hayvanlar" bottom sheet, animal report cards, and the animal report detail screen.

IMPORTANT:
Do not redesign the existing UI.
Preserve the current map, marker, bottom sheet, card, filter, and report detail visual design.

The task is about navigation, data relationships, state synchronization, and interaction behavior.

==================================================
CORE EXPECTED BEHAVIOR
==================================================

Each animal report shown on the map must represent exactly one real animal report record from the database.

When the user taps a paw/status marker on the map:

1. Detect the exact animal report associated with the tapped marker.
2. Read the marker's report ID.
3. Find the matching animal card inside the "Yakındaki Hayvanlar" bottom sheet.
4. Automatically expand/open the bottom sheet if necessary.
5. Automatically scroll the animal card list to the matching report.
6. Bring the matching card into a clearly visible position.
7. Temporarily highlight/select the matching card.
8. Keep the map marker and card selection synchronized.

Example:

Marker:
report_id = "report_123"

Animal card:
report_id = "report_123"

Animal detail screen:
report_id = "report_123"

These must all represent the SAME database record.

Never match reports by:
- title
- animal name
- coordinates only
- array index
- visual order
- status label

Always use the unique report ID / primary key.

reports

    report => report.id === reportId

    return;

  setSelectedReportId(reportId);
