BU GÖREVDE YENİ ÜRÜN ÖZELLİĞİ EKLEME.

Amaç:

CanYoldaşı uygulamasını App Store / Google Play yayını öncesinde teknik olarak uçtan uca denetlemek, gerçek root cause problemlerini tespit etmek ve mevcut özellikleri güvenilir, kalıcı ve platformlar arası tutarlı hale getirmektir.

Uygulamada daha önce tekrar eden kritik problem örnekleri:

- Fotoğraf seçiliyor ancak daha sonra kartlarda görünmüyor.
- Local image URI yanlışlıkla persist ediliyor olabilir.
- Supabase Storage upload zincirleri tutarsız olabilir.
- Kullanıcı konum seçiyor ancak yayınlanan durumda "Konum Belirtilmedi" görünüyor.
- UI state güncelleniyor ancak database write eksik kalabiliyor.
- Kalp / takip işlemleri local state'te görünüp database relation'a yansımayabiliyor.
- API JSON beklerken HTML response geliyor.
- "JSON Parse error: Unexpected character: <" hataları oluşuyor.
- iOS'ta çalışan değişiklik Android veya Web'de aynı sonucu vermeyebiliyor.
- Query, mapper ve UI farklı field isimleri okuyabiliyor.
- Stale navigation params veya cache nedeniyle eski data gösterilebiliyor.
