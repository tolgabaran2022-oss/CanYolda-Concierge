TEK ORTAK PREMIUM MODAL KULLAN

Evcilim ekranında tüm Premium giriş noktaları için tek modal kullan:

type PremiumEntry = {
  source: string;
  returnTo?: string;
};

const [premiumModalOpen, setPremiumModalOpen] = useState(false);
const [premiumEntry, setPremiumEntry] =
  useState<PremiumEntry | null>(null);

Merkezi açma fonksiyonu:

const showPremiumModal = (
  source: string,
  returnTo?: string
) => {
  setPremiumEntry({ source, returnTo });
  setPremiumModalOpen(true);
};

Tek modal:

<EvcilimPremiumModal
  visible={premiumModalOpen}
  source={premiumEntry?.source}
  returnTo={premiumEntry?.returnTo}
  onClose={() => {
    setPremiumModalOpen(false);
    setPremiumEntry(null);
  }}
/>

Mevcut component prop tiplerine göre düzenle. Aynı ekranda Belgeler için ayrı, İlaçlar için ayrı ve ikinci hayvan için ayrı modal instance oluşturma.

İKİNCİ HAYVAN BUTONU

“Evcil Hayvan Ekle” butonunun yalnızca aşağıdaki merkezi fonksiyona bağlı olduğundan emin ol:

onPress={handleAddPet}

Butonda veya onu saran component içinde doğrudan /evcilim/add navigasyonu bulunmamalı.

Mantık:

const handleAddPet = async () => {
  if (addingPetLockRef.current) return;

  addingPetLockRef.current = true;
  setAddingPet(true);

  try {
    const latestStatus = await refreshPetPremiumStatus(false);

    if (!latestStatus) {
      throw new Error("Premium status could not be loaded");
    }

    if (latestStatus.canAddPet === true) {
      router.push("/evcilim/add");
      return;
    }

    showPremiumModal(
      "add_second_pet",
      "/evcilim/add"
    );
  } catch (error) {
    Alert.alert(
      "İşlem gerçekleştirilemedi",
      "Evcil hayvan bilgilerin kontrol edilemedi. Lütfen tekrar dene."
    );
  } finally {
    addingPetLockRef.current = false;
    setAddingPet(false);
  }
};

ÖNEMLİ:

refreshPetPremiumStatus(false) fonksiyonunun gerçek dönüş tipini incele. Eğer fonksiyon güncel status döndürmüyor ve sadece context state’ini güncelliyorsa, hemen ardından eski premiumStatus.canAddPet değerini okumak stale-state hatasına yol açar.

Bu durumda fonksiyonu güncel sonucu döndürecek şekilde düzenle:

const latestStatus = await refreshPetPremiumStatus(false);

ve kararı doğrudan latestStatus.canAddPet üzerinden ver.

Kararı async state güncellemesinden hemen sonra eski context state’i üzerinden verme.

PREMIUM ÖZELLİK KARTLARI

Belgeler ve İlaçlar mevcut çalışan yapısını korusun:

const handlePremiumFeature = async (
  source: string,
  destination: string
) => {
  if (premiumActionLockRef.current) return;

  premiumActionLockRef.current = true;

  try {
    const latestStatus = await refreshPetPremiumStatus(false);

    if (latestStatus?.isPremium === true) {
      router.push(destination);
      return;
    }

    showPremiumModal(source, destination);
  } catch {
    Alert.alert(
      "İşlem gerçekleştirilemedi",
      "Premium üyelik durumun kontrol edilemedi."
    );
  } finally {
    premiumActionLockRef.current = false;
  }
};

İkinci hayvan kontrolünde isPremium yerine backend’in hesapladığı canAddPet kullanılmalı.

Belgeler ve İlaçlar kontrolünde ise gerçek Premium alanı kullanılmalı.

Bunları birbirine karıştırma:

İkinci hayvan → canAddPet
Premium özellikler → isPremium/isActive

SATIN ALMA SONRASI HEDEF

Modalın hangi kaynaktan açıldığını koru:

source = add_second_pet
→ Satın alma doğrulanınca /evcilim/add

source = documents
→ Satın alma doğrulanınca Belgeler

source = medications
→ Satın alma doğrulanınca İlaçlar

Satın alma tamamlandıktan sonra:

Backend Premium durumu yeniden çekilsin.
Gerçekten aktif olduğu doğrulansın.
Modal kapatılsın.
premiumEntry.returnTo route’una gidilsin.
premiumEntry yalnızca navigation hedefi alındıktan sonra temizlensin.
