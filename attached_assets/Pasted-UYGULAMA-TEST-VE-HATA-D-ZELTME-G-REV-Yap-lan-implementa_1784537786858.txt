ÖNEMLİ OLASI RACE CONDITION

React state güncellemeleri anlık olmadığı için şu kontrol tek başına hızlı çift dokunmayı kesin olarak engellemeyebilir:

if (addingPet) return;

Aynı render döngüsündeki iki hızlı dokunmada her iki çağrı da `addingPet === false` görebilir.

Bunu `useRef` tabanlı senkron kilitle güvenceye al:

```tsx
const addingPetLockRef = useRef(false);

const handleAddPet = async () => {
  if (addingPetLockRef.current) return;

  addingPetLockRef.current = true;
  setAddingPet(true);

  try {
    // Mevcut karar ve yönlendirme mantığı
  } catch (error) {
    // Mevcut hata yönetimi
  } finally {
    addingPetLockRef.current = false;
    setAddingPet(false);
  }
};

Modal açıldığında ve forma yönlendirme tamamlandığında kilidin doğru zamanda kaldırıldığını doğrula. Kilidin kalıcı olarak takılı kalmasına izin verme.

ÖRNEK KARAR FONKSİYONU

const addPetLockRef = useRef(false);

const handleAddPetPress = async () => {
  if (addPetLockRef.current) return;

  addPetLockRef.current = true;
  setAddingPet(true);

  try {
    // Local pets.length değerine güvenme.
    // Backend’den bu kullanıcıya ait gerçek aktif hayvan sayısını al.
    const petCount = await fetchCurrentUserPetCount();

    if (petCount === 0) {
      router.push('/evcilim/add');
      return;
    }

    // Kullanıcının en az bir hayvanı varsa Premium durumunu
    // backend üzerinden güncel olarak doğrula.
    const premiumStatus = await refreshPetPremiumStatus();

    if (premiumStatus?.isActive === true) {
      router.push('/evcilim/add');
      return;
    }

    // Ücretsiz kullanıcı: form açılmayacak.
    setPremiumModalOpen(true);
  } catch (error) {
    Alert.alert(
      'İşlem gerçekleştirilemedi',
      'Evcil hayvan ve Premium bilgilerin kontrol edilemedi. Lütfen tekrar dene.'
    );
  } finally {
    addPetLockRef.current = false;
    setAddingPet(false);
  }
};

Buradaki fonksiyon ve dönüş değerlerini projedeki gerçek API/hook yapısına göre düzenle. Örnek kodu körü körüne kopyalama.

ÖNEMLİ: GERÇEK HAYVAN SAYISI

İkinci hayvan kontrolünü yalnızca pets.length ile yapma.

Backend’de mevcut kullanıcı kimliğine göre gerçek kayıt sayısını sorgula. Yalnızca kullanıcıya ait, silinmemiş/aktif evcil hayvanları say.

Örnek mantık:

SELECT COUNT(*)
FROM pets
WHERE user_id = authenticated_user_id
AND deleted_at IS NULL;

Projede tablo veya kolon adları farklıysa gerçek şemayı kullan.

Güvenlik açısından kullanıcı kimliğini client tarafından gönderilen rastgele bir ID’den alma. Authenticated session kullanıcı kimliğini kullan.

KRİTİK GÜVENLİK KURALI

Sadece UI butonunu kilitlemek yeterli değildir.

Evcil hayvan oluşturma API endpoint’inde de server-side kontrol ekle:

Kullanıcının mevcut evcil hayvan sayısı 0
→ Oluşturmaya izin ver

Mevcut hayvan sayısı >= 1 ve Premium aktif
→ Oluşturmaya izin ver

Mevcut hayvan sayısı >= 1 ve Premium aktif değil
→ 403 PET_PREMIUM_REQUIRED döndür

Böylece kullanıcı /evcilim/add adresini doğrudan açsa bile Premium olmadan ikinci hayvanı kaydedemez.

403 yanıtında:

Oluşturma işlemini durdur.
“İkinci evcil hayvan için Evcilim Premium gereklidir.” mesajını göster.
Kullanıcıyı Premium karta yönlendir.
Form verilerini mümkünse kaybetme.
