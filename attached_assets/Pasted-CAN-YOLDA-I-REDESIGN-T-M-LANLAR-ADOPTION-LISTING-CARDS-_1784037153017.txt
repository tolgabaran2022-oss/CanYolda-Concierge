Redesign only the visual presentation and responsive layout of:

Sahiplendirme
→ Tüm İlanlar

IMPORTANT:

Do not change the existing adoption listing backend logic.

Do not change:

- listing creation
- listing ownership
- favorites
- filters
- search
- promoted listing ranking
- promotion expiration
- messaging
- adoption request flow

This task is a focused UX/UI redesign of the public adoption listing discovery screen.

Preserve the existing CanYoldaşı purple/lilac premium design system.

==================================================
CURRENT DESIGN PROBLEMS
==================================================

The current listing cards are visually too tall and inefficient.

Current problems include:

- listing images consume excessive vertical space
- only a very small number of listings fit on one screen
- long descriptions are displayed directly on the listing card
- long text can visually break card hierarchy
- the current "İletişim" button is redundant with the listing detail messaging/adoption flow
- listing metadata is not clearly grouped
- cards do not clearly emphasize pet name, age, breed, gender, and location
- promoted listing state needs a more premium but subtle visual treatment
- unrelated/missing images can make the screen look broken
- vertical spacing is inconsistent
- the current design feels less premium than the rest of the CanYoldaşı application

Redesign this screen without changing the complete Sahiplendirme feature architecture.

==================================================

Create a modern, compact, premium adoption listing card.
