REVENUECAT SERVİSİ

fetchPetPremiumOfferings() fonksiyonunu şu mantıkla uygula:

import Purchases, {
  type PurchasesPackage,
} from "react-native-purchases";

const PET_PREMIUM_OFFERING_ID =
  "canyoldasi_pet_premium";

export async function fetchPetPremiumOfferings():
  Promise<PurchasesPackage[]> {

  const offerings = await Purchases.getOfferings();

  const offering =
    offerings.all[PET_PREMIUM_OFFERING_ID];

  if (!offering) {
    throw new Error(
      `RevenueCat offering bulunamadı: ${PET_PREMIUM_OFFERING_ID}`
    );
  }

  const packages = offering.availablePackages;

  if (!packages || packages.length === 0) {
    throw new Error(
      `RevenueCat offering içinde paket bulunamadı: ${PET_PREMIUM_OFFERING_ID}`
    );
  }

  return packages;
}

Projede RevenueCat için mevcut wrapper, loglama veya hata sınıfları varsa mevcut mimariye uygun şekilde düzenle.

PAKET FİLTRELEME VE SIRALAMA

Evcilim Premium ekranında yalnızca şu paketleri kabul et:

$rc_monthly
$rc_annual

Bazı SDK cevaplarında identifier farklı biçimde dönebileceği için gerçek response’u loglayıp kontrol et.

Güvenli filtre:

const supportedIds = new Set([
  "$rc_monthly",
  "$rc_annual",
]);

const packages = offering.availablePackages
  .filter((pkg) => supportedIds.has(pkg.identifier))
  .sort((a, b) => {
    if (a.identifier === "$rc_monthly") return -1;
    if (b.identifier === "$rc_monthly") return 1;
    return 0;
  });

Filtre sonucunda paket yoksa sessizce boş liste döndürme; anlamlı hata üret.

UI GÖSTERİMİ

evcilim-premium.tsx içinde paketleri gerçek RevenueCat verileriyle göster:

Başlık ve süreyi yalnızca RevenueCat ürün başlığına güvenerek oluşturma. Package identifier’a göre kullanıcı dostu Türkçe metin göster:

function getPackagePresentation(
  pkg: PurchasesPackage
) {
  switch (pkg.identifier) {
    case "$rc_monthly":
      return {
        title: "Evcilim Premium Aylık",
        description: "Her ay yenilenir",
      };

    case "$rc_annual":
      return {
        title: "Evcilim Premium Yıllık",
        description: "Her yıl yenilenir",
      };

    default:
      return {
        title: pkg.product.title,
        description:
          pkg.product.description ||
          "Evcilim Premium erişimi",
      };
  }
}

Fiyat kesinlikle RevenueCat’ten gelsin:

pkg.product.priceString

Sahte veya sabit fiyat yazma.

Varsayılan olarak yıllık paketi seç:

const annual =
  items.find(
    (pkg) => pkg.identifier === "$rc_annual"
  );

setSelected(annual ?? items[0] ?? null);

SATIN ALMA

Kullanıcı “Premium’a Geç” butonuna bastığında seçili PurchasesPackage ile mevcut satın alma servisini çağır:

await Purchases.purchasePackage(selectedPackage);

Mevcut purchasePetPremium(selected) wrapper’ı doğru çalışıyorsa onu koru.

Satın alma tamamlandığında yalnızca client cevabına güvenme.

Şu sırayı uygula:

1. RevenueCat purchasePackage başarılı
2. RevenueCat CustomerInfo alınır
3. Beklenen entitlement aktifliği kontrol edilir
4. Backend Premium refresh endpoint’i çağrılır
5. Backend’den isPremium === true doğrulanır
6. Modal kapatılır
7. Kullanıcı geldiği özelliğe yönlendirilir

ENTITLEMENT

Önce RevenueCat dashboard veya mevcut koddan gerçek entitlement identifier’ını tespit et.

Beklenen identifier:

pet_premium

Ancak dashboard/kod farklı bir gerçek identifier kullanıyorsa bunu raporla ve tek bir sabitte standartlaştır.

Örnek:

const PET_PREMIUM_ENTITLEMENT_ID =
  "pet_premium";

const customerInfo =
  await Purchases.getCustomerInfo();

const activeEntitlement =
  customerInfo.entitlements.active[
    PET_PREMIUM_ENTITLEMENT_ID
  ];

if (!activeEntitlement) {
  throw new Error(
    "Evcilim Premium entitlement aktifleşmedi."
  );
}

Entitlement henüz RevenueCat’te tanımlı veya ürünlere bağlı değilse kodla bu eksikliği gizleme. Açıklayıcı hata üret ve raporla:

RevenueCat’te pet_premium entitlement oluşturulmalı ve Monthly/Yearly ürünleri bu entitlement’a bağlanmalıdır.
