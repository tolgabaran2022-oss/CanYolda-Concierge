CAN YOLDAŞI — PHASE 0 PRODUCTION READINESS AUDIT

Perform a comprehensive, read-only production readiness audit of the entire CanYoldaşı mobile application.

IMPORTANT RULES:

* Do not modify any code.
* Do not automatically fix any issue.
* Do not delete or migrate any database table.
* Do not install, uninstall, or upgrade packages.
* Do not change environment variables.
* Do not expose secret keys, access tokens, passwords, service-role keys, private URLs, or user data.
* Mask all sensitive values in the report.
* Inspect the actual project files and configuration. Do not provide generic recommendations.
* Every finding must include evidence: file path, component, function, database table, policy, configuration field, or reproducible flow.
* If something cannot be verified, clearly mark it as “NOT VERIFIED”.
* Do not claim that something works merely because code exists.
* Separate implemented functionality from functionality that has been tested successfully.

PROJECT CONTEXT

CanYoldaşı is a React Native / Expo pet community application.

Known technologies:

* Expo SDK 54
* React Native 0.81.5
* React 19
* TypeScript
* Supabase Authentication
* Supabase PostgreSQL
* Supabase Storage
* RevenueCat / react-native-purchases 10.4.2
* Google Sign-In
* Apple Sign-In

Primary application areas:

* Authentication

* Direct messaging
* User profiles
* Follow system

* Saved listings
* Privacy settings
* Account deletion

The old social Feed/Akış feature has been removed. Check whether unused feed code, database tables, routes, permissions, storage folders, hooks, API functions, navigation entries, notification types, or dependencies still remain.
