13. ACTIVE PROMOTION STACKING RULE
==================================================

Use the following CanYoldaşı promotion extension logic:

If listing is NOT currently promoted:

starts_at = now()
expires_at = now() + packageDuration

If listing is already promoted and promoted_until > now():

new expiration should EXTEND the current promotion.

Example:

Current promoted_until:
20 July 2026

User buys 3-day boost:

New promoted_until:
23 July 2026

Do not silently replace the remaining active boost.

Server-side logic:

baseTime = max(now(), currentPromotedUntil)

newPromotedUntil = baseTime + productDuration

Perform this update transactionally to prevent race conditions.
