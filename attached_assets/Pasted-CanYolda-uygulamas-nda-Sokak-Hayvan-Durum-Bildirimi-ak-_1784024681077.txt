Şu katmanları karşılaştır:

Tek bir canonical location model kullan.

Önerilen frontend modeli:

type GeoLocation = {
  latitude: number;
  longitude: number;
  address?: string | null;
};

type AnimalHelpReport = {
  id: string;
  location: GeoLocation | null;
};

Database mevcut şemasına göre data layer'da normalize et.

Örnek:

function normalizeReportLocation(row: any): GeoLocation | null {
  const latitude =
    row.latitude ??
    row.location_lat ??
    row.lat ??
    null;

  const longitude =
    row.longitude ??
    row.location_lng ??
    row.lng ??
    row.lon ??
    null;

  if (
    typeof Number(latitude) !== "number" ||
    typeof Number(longitude) !== "number"
  ) {
    return null;
  }

  const parsedLatitude = Number(latitude);
  const parsedLongitude = Number(longitude);

  if (
    !Number.isFinite(parsedLatitude) ||
    !Number.isFinite(parsedLongitude)
  ) {
    return null;
  }

  return {
    latitude: parsedLatitude,
    longitude: parsedLongitude,
    address:
      row.location_address ??
      row.address ??
      null,
  };
}

Daha doğru type guard uygula.

Compatibility logic'i UI component'lerinin içine dağıtma.

  throw new Error("LOCATION_REQUIRED");

  // existing report fields

  latitude: selectedCoords.latitude,
  longitude: selectedCoords.longitude,
  location_address: selectedCoords.address ?? null,

  .from(REPORT_TABLE)
  .insert(insertPayload)
  .select()
  .single();

  console.error("[ANIMAL REPORT INSERT ERROR]", error);
  throw error;
}

console.log("[ANIMAL REPORT INSERT RESULT]", data);

==================================================
11. REVERSE GEOCODING EKLE / KONTROL ET
==================================================

Kullanıcı konumu seçtiğinde koordinatlardan okunabilir adres üret.

Expo Location kullanılıyorsa:

const results = await Location.reverseGeocodeAsync({
  latitude,
  longitude,
});

İlk sonucu kullan.

Örnek format:

Kadıköy, İstanbul

veya:

Dinar, Afyonkarahisar

Bir helper oluştur:

function formatLocationLabel(result: Location.LocationGeocodedAddress) {
  const parts = [
    result.district,
    result.subregion,
    result.city,
    result.region,
  ]
    .filter(Boolean)
    .filter(
      (value, index, array) =>
        array.indexOf(value) === index
    );

  return parts.slice(0, 2).join(", ");
}

Eğer reverse geocoding başarısız olursa koordinatları kaybetme.

Coordinates source of truth olmalı.

Address optional metadata olmalı.
