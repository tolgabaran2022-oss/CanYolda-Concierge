Mevcut “İlanlarım” kartındaki “Önizle” butonunu tamamen çalışır hale getir.

AMAÇ:
Kullanıcı kendi ilan kartında “Önizle” butonuna tıkladığında, ilan sahibinden.com mantığında gerçek ilan detay sayfası olarak açılsın. Önizleme ekranı, ilanın diğer kullanıcılar tarafından nasıl görüleceğini göstermelidir.

ÖNEMLİ:
- Sahte veya boş bir modal açma.
- Mevcut ilan verilerini kullan.
- İlan başlığı, açıklaması, fiyatı, konumu, görselleri, özellikleri ve ilan sahibi bilgileri Supabase’den gelsin.
- Mevcut backend, auth ve veritabanı yapısını bozma.
- “Önizle” butonu sadece görsel bir buton olarak kalmasın.
- Web ve mobil görünümde çalışsın.
- İlan kartındaki mevcut tasarımı değiştirme.

1. ÖNİZLE BUTONU DAVRANIŞI

Karttaki “Önizle” butonuna tıklanınca:

- İlanın gerçek detail/preview sayfasına yönlendir.
- Route örneği:
  /ilan/[listingId]
  veya
  /listings/[listingId]/preview

- listingId karttaki gerçek ilan id değerinden gelsin.
- Sabit, rastgele veya örnek id kullanma.
- İlan bulunamazsa düzgün bir “İlan bulunamadı” ekranı göster.
- Yüklenirken skeleton/loading göster.
- Butona art arda basıldığında birden fazla navigation oluşmasın.

Örnek davranış:

onPreview={() => router.push(`/ilan/${listing.id}?preview=true`)}

Proje Expo Router kullanıyorsa:
router.push({
  pathname: "/ilan/[id]",
  params: {
    id: listing.id,
    preview: "true"
  }
})

React Router kullanıyorsa:
navigate(`/ilan/${listing.id}?preview=true`)

Next.js kullanıyorsa:
router.push(`/ilan/${listing.id}?preview=true`)

Projede hangi routing sistemi varsa ona uygun olanı kullan.

2. ÖNİZLEME EKRANININ AMACI

Bu ekran, ilan yayınlandığında diğer kullanıcıların göreceği ilan detay ekranıyla aynı olmalıdır.

Ancak ilan sahibi önizleme modundayken:
- Üstte küçük bir “Önizleme Modu” etiketi göster.
- “Bu ilan diğer kullanıcılara bu şekilde görünecek.” açıklaması göster.
- İlan sahibine ait “Mesaj Gönder” veya “Ara” butonları kendisine karşı aktif olmasın.
- Bunun yerine “İlanı Düzenle” ve “Önizlemeden Çık” butonları gösterilebilir.
- Görüntülenme sayısını önizleme sırasında artırma.
- Önizleme açılması gerçek ilan görüntülenmesi olarak kaydedilmesin.

3. İLAN DETAY SAYFASI

Sayfa sahibinden.com ilan detay mantığında düzenlensin.

ÜST ALAN:
- Geri butonu
- “İlan Detayı” başlığı
- Favoriye ekleme ikonu
- Paylaşma ikonu
- Önizleme modundaysa “Önizleme” etiketi

GÖRSEL GALERİSİ:
- İlanın tüm görselleri gösterilsin.
- İlk görsel büyük ana görsel olsun.
- Diğer görseller küçük thumbnail olarak gösterilsin.
- Görsele tıklanınca tam ekran galeri açılsın.
- Mobilde swipe ile görseller arasında geçiş yapılabilsin.
- Görsel sayacı göster:
  “1 / 5”
- Görsel yoksa ilan türüne uygun placeholder göster.
- object-fit: cover kullan.
- Görseller kırpılmış veya ezilmiş görünmesin.

İLAN BAŞLIĞI:
- Büyük ve okunabilir başlık
- Altında ilan numarası
- Yayınlanma tarihi
- Konum bilgisi
- İlan durumu: Aktif / Pasif

Örnek:
“Golden Retriever 3 Aylık Yavru”
“İlan No: 12345678”
“Çıldır, Ardahan”
“Bugün yayınlandı”

FİYAT ALANI:
İlanda fiyat varsa:
- Büyük ve dikkat çekici şekilde göster.
- Para birimini doğru göster.
- Örnek: “12.500 TL”

İlan ücretsiz sahiplendirme ise:
- Fiyat yerine “Ücretsiz Sahiplendirme” göster.

İlan fiyat alanı boşsa:
- Rastgele fiyat üretme.
- “Fiyat belirtilmedi” göster.

9. ÖNİZLEME VE NORMAL DETAY AYRIMI

URL’de preview=true varsa:
- previewMode = true yap.
- Görüntülenme sayısını artırma.
- İletişim butonlarını ilan sahibine göre değiştir.
- Üstte önizleme bilgilendirme bandı göster.

preview parametresi yoksa:
- Normal ilan detay ekranı olarak aç.
- Kullanıcı ilan sahibi değilse görüntülenme sayısını bir kez artır.
- Aynı kullanıcının sayfayı sürekli yenilemesi görüntülenmeyi spam şekilde artırmasın.
- Oturum veya kullanıcı bazlı view deduplication uygula.

16. ÖNİZLE BUTONUNU BAĞLA

Mevcut kart componentinde Önizle butonunun onPress/onClick olayını bul.

Şu hataları kontrol et:
- onPress verilmemiş olması
- yanlış fonksiyon adı kullanılması
- listing.id undefined olması
- TouchableOpacity veya Pressable disabled olması
- üstünde başka görünmez component bulunması
- pointerEvents nedeniyle tıklanmaması
- web tarafında button type hatası
- route dosyasının eksik olması
- yanlış pathname kullanılması

Buton yapısı örnek:

<Pressable
  onPress={() => handlePreview(listing.id)}
  disabled={isNavigating}
  accessibilityRole="button"
  accessibilityLabel="İlanı önizle"
>
  <EyeIcon />
  <Text>Önizle</Text>
</Pressable>

handlePreview fonksiyonu:

const handlePreview = (listingId: string) => {
  if (!listingId || isNavigating) return;

  setIsNavigating(true);

  router.push({
    pathname: "/ilan/[id]",
    params: {
      id: listingId,
      preview: "true"
    }
  });
};

Navigation sonrası loading state düzgün temizlensin.
