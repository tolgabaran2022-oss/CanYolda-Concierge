[8] KRİTİK HATA DÜZELTMESİ — StatusBadge "Cannot read property 'bg'" Çöküşü
    Commit: "Fix error when displaying animal status by normalizing Turkish values"
    Dosya: artifacts/mobile/contexts/AnimalsContext.tsx
             artifacts/mobile/components/StatusBadge.tsx
────────────────────────────────────────────────────────────────────────────────
Hata  : Hayvanlar sekmesi veya harita ekranı açıldığında uygulama
        "Render Error: Cannot read property 'bg' of undefined" hatasıyla
        çöküyordu.
Neden : Seed verisi veritabanına Türkçe status değerleri kaydetti
        ("aç", "yaralı", "sağlıklı", "bilinmiyor"). Yeni kullanıcı
        kayıtları ise İngilizce kayıt ediyor ("hungry", "injured").
        StatusBadge sadece İngilizce anahtarları tanıyan bir map kullanıyor.
        STATUS_CONFIG["aç"] → undefined → .bg erişiminde crash.
Çözüm :
  1. AnimalsContext.tsx → normalizeStatus() fonksiyonu eklendi:
        "aç" → "hungry", "yaralı" → "injured",
        "sağlıklı" → "healthy", "bilinmiyor" → "unknown"
     API'den gelen tüm status değerleri İngilizce'ye çevriliyor.
  2. StatusBadge.tsx → güvenlik fallback eklendi:
        STATUS_CONFIG[status] ?? STATUS_CONFIG.unknown
     Tanımlanmayan bir değer gelse bile crash olmuyor.
Sonuç : Render Error yok, hayvanlar listesi düzgün yükleniyor ✅
